# Cafuné Cosmética Natural - E-commerce

**Sitio web oficial:** [cafunecosmeticanatural.com](https://cafunecosmeticanatural.com)

### Sobre el proyecto
Desarrollo completo de un **e-commerce estático** para una marca de cosmética natural en Córdoba, Argentina. Primer proyecto freelance entregado.

### Funcionalidades principales
- Diseño **100% responsive** (Mobile First)
- Navegación con menú hamburguesa y dropdown
- Filtros por categoría + buscador
- Grilla de productos con paginación
- Overlay de producto con galería, lightbox y variantes
- **Carrito lateral** con persistencia
- **Checkout de 3 pasos** con barra de progreso
- Integración con **EmailJS** para pedidos y contacto
- Combos con cálculo dinámico de precios

### Tecnologías utilizadas
- HTML5
- CSS3 (Flexbox + Grid)
- Vanilla JavaScript
- EmailJS
- Netlify (deploy)
- SEO básico (Meta tags, Open Graph, JSON-LD)

### Decisiones de arquitectura
- 100% estático a pedido del cliente para abaratar costos de mantenimiento (sin backend)
- Catálogo de productos en un array JavaScript
- Hosting gratuito en Netlify + dominio propio
